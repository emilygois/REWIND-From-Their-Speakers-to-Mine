REWIND: From Their Speakers to Mine

Emily Gois — 52685 Creative Coding, Assessment 2

ABOUT THE PROJECT

REWIND explores nostalgia by connecting music I heard through my parents with music I enjoy myself. I created the composition in TunePad using Python.

The opening draws on “Pump Up the Jam”, “Show Me Love” and “This Is Your Night”, using a steady dance beat and short, punchy notes. The second section draws on Chris Brown and Usher, using smoother notes and more varied drums.

HOW TO RUN IT

1. Open my TunePad project.
2. Turn on your device’s sound.
3. Play the complete project with all five cells enabled.

The composition runs at 120 BPM and lasts approximately 1 minute and 36 seconds. These code files use TunePad’s built-in commands and instruments, so they need to run in TunePad.

The audio folder contains the finished MP3.
